# Unity gameplay with coherent arms

Actual Unity golf gameplay with simulated phone input: 720×480, 60 fps, 6 seconds each. All 360 frames of each video decode successfully. These captures demonstrate the shared character-arm correction; they are not Blender renders or physical-device performance tests.

The same sport-independent component is tested with actual tennis, bowling and boxing poses for both character identities. See [implementation and limits](../../CHARACTER-ARMS.md).
