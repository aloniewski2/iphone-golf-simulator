# Unity tennis rally lab

- [Male tennis gameplay](male-tennis-rally-60fps.mp4)
- [Female tennis gameplay](female-tennis-rally-60fps.mp4)
- [Live hit-quality feedback](tennis-live-hit-feedback.png)

Actual Unity resort scene, permanent floating-hands characters, existing tennis animations and racket, running/stamina and live hit feedback. The six-second, 60 fps test captures inject a controlled contact fixture into the actual collision path to demonstrate a hit. They are not a physical phone recording or an AI opponent benchmark.

See [controls, functionality and prototype limitations](../../TENNIS-GAMEPLAY.md).
