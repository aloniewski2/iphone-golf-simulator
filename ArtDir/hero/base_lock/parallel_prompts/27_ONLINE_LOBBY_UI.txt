PASTE: ONLINE PLAY + SHARED LOBBY UI (Codex Goal Mode, GPT-6.1 Sol). NEW CHAT.

GOAL
Build the online play and lobby front end for Party Sports in the EXISTING Island design system. When a player invites a friend (or gets matched, or joins nearby), the friend's hero appears in the lobby BESIDE the host's hero, live, in their own locker look. Everyone in the lobby can play emotes and change clothes, and the others see it happen in the same lobby. Then the host starts a tennis or golf match from there. Done = every gate passes AND the screenshots and films read as the same game as the current menus and locker. Adnan's eye overrides any PASS.

2. HARD RULES
- Design: no new colours, fonts, corner radii, or focus styles. Use IslandUI tokens and Island components. A new component is allowed only when no Island one fits; it goes in IslandKit.swift, in the same style, and is listed in the report.
- Every focusable element goes through the TennisMenu focus grid with a tap id, works with the click remote (move + A select + B back), and works with touch. No swipe gestures anywhere.
- Do not touch Unity gameplay, match clips (Serve, emotes, etc.), hero meshes, shaders, golf course files, QualitySettings, URP assets, or the tennis rules.
