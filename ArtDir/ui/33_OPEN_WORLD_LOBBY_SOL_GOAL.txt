3. ARCHITECTURE DECISION (binding unless P1 gate H1.6 fails)
======================================================================
The hub is a native SceneKit scene inside the SwiftUI shell, at a NEW folder GolfArcade/Hub/. It is NOT a Unity scene. Reasons, all from the code:
  a) Unity loads only for a match (SportsRuntime.loadInWindow; NativeSportsSession loads "Tennis"/"Golf" by name). Booting Unity for the menu would add load
     time and memory before every match and fight the match handoff.
  b) The heroes already render in SceneKit with the real rig, kit colours and emotes (MatchHero.build, HeroRig, LobbyHeroStage). 4 heroes measured at 60 fps.
  c) The menu already renders on the TV through TennisTVRoot. A SceneKit view inside TennisMenuScreen shows on the phone and on the TV with no new display path.
  d) Unity/Assets/** is the busiest contested area (126 modified script paths in the working tree right now). Staying in Swift avoids collisions.
Fallback rule: if H1.6 (graybox ≥ 55 fps p95 on iPhone 15-class with 4 heroes) FAILS, STOP and write work/hub/ARCH_FALLBACK.md with the numbers.
  Do not switch engines without Adnan.

Scene architecture (one scene, zones as named subtrees, no streaming needed at this size):
  HubScene (SCNScene, NEW)
   ├─ Zone_Plaza   ├─ Zone_Locker   ├─ Zone_PlayGate   ├─ Zone_Terrace   ├─ Zone_ProShop
   │    each zone node contains ONLY these standard children (names are the contract):
   │      Geo_*            replaceable geometry (graybox now, kit later; never referenced by code)
   │      Col_*            collision footprints (boxes/cylinders on the XZ plane) -> baked into the nav grid
   │      Anchor_Stand_<stationID>    where the hero stands to use a station (position + facing)
   │      Anchor_Look_<stationID>     camera focus when that station's panel opens
   │      Volume_Prompt_<stationID>   cylinder trigger (radius in HubLayout, not in geometry)
   │      Cam_<zoneID>                camera rail parameters (yaw, distance, height, pitch)
   │      Sign_<zoneID>               signage anchor (text comes from HubLayout, never baked into textures)
   │      Spot_Party_<n>              party presence spots (terrace only)
   ├─ Landmark_Tower (central vertical landmark, visible from every walkable cell)
   ├─ Spawn_Default, Spawn_Return_Tennis, Spawn_Return_Golf, Spawn_Return_Party
   ├─ Heroes (local hero + up to 3 party heroes)
   └─ Light_Key (1 directional, shadows), Light_Fill (ambient), optional Backdrop_Far (one ClubEnvironment room as a far card, never walkable)
HubLayout.swift is the single source of truth for coordinates, radii, speeds and station→action mapping. Geometry is authored to match HubLayout,
never the other way round. Art swaps (§9) replace Geo_* only and must pass the same layout tests.

7.1 Phone, no TV (TennisPhoneMenu, portrait)

7.2 TV / Mac connected (menu on TV via TennisTVRoot, phone = TennisRemote)
  - DPad: hold an arrow = jog in that camera-relative direction (hold-to-repeat semantics, no swipe; two arrows held = diagonal). Single click = 0.5 m step.

  - Third-person chase, fixed per-zone yaw rails: Plaza 0°, PlayGate 0°, Locker −90° (looking west into the open front), Terrace +90°, ProShop 0°.
    Yaw blends over 0.6 s when the hero crosses a zone threshold. The player can't orbit (phones get lost, TV remotes can't orbit).

  - FOV like ClubEnvironmentSceneView: 55° vertical in portrait, 60° horizontal in landscape/TV.

  - Trigger = cylinder at the station's Anchor_Stand with radius in/out hysteresis (table §5). The nearest eligible station wins, then registry order.

9.1 Customizability rule (new clothes/skins/tools must never break the hub)
  C1  Heroes are built ONLY through MatchHero.build(player, sport:, distance:) + HeroRig. The hub never loads meshes, materials or kit textures itself.

      HubSocketMap that resolves names: Hand_Racket, Hand_L today; HairRoot / Headwear / Chest_Top / Hip_Bottom / Foot_L_Shoe / Foot_R_Shoe when they exist.

      tool can't change reachability or framing.

      Swapping must not rebuild other heroes.
